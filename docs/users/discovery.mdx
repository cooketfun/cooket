---
title: "Discover tokens"
description: "Browse newest, trending, and searchable launches."
---

The marketplace uses indexed Arc Testnet data. It does not generate placeholder tokens or browser-calculated market data.

- **Newest** uses canonical launch ordering.
- **Trending** ranks indexed recent volume, trade count, and trader count.
- **Search** matches token name, symbol, or address prefix using a normalized query.
- **Creator pages** list canonical launches attributed to a creator address.

Cards and token pages can show indexed trade counts, volume, holders, current price, fully diluted value, lifecycle, and social metadata when those values are available. Missing or incomplete data remains unavailable rather than being synthesized.

<Note>
  Discovery is an application view of indexed events, not a trust list or endorsement. An application exclusion can hide an exceptional launch from derived discovery views without changing or deleting its onchain existence or canonical raw event record.
</Note>
