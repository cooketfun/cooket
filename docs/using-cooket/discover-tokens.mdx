---
title: "Discover tokens"
description: "Browse canonical indexed launches and market views."
---

Discovery uses the indexed API; it does not generate placeholder launches or infer missing market data.

- **New** lists canonical launches in newest-first order.
- **Top** uses indexed discovery metrics.
- **Near** filters tokens near the curve endpoint according to repository query logic.
- **Linked** filters launches with social or website metadata.
- **Trending** uses indexed recent volume, trade count, and trader count.
- **Search** matches normalized name, symbol, and address prefixes.

Creator pages and wallet holdings are also indexed projections. A token can exist onchain before appearing in these views, and application exclusions can remove exceptional tokens from derived product views without deleting onchain history.

<Note>Discovery ranking is not a recommendation, audit, verification, or endorsement.</Note>
