The frontend, API, and indexer in this repository accept only Arc Testnet.
Base Mainnet and Base Sepolia IDs are rejected. No Arc mainnet configuration is
present.

Arc native USDC uses 18 decimals. The Arc USDC ERC-20 interface uses 6 decimals;
applications must never mix those representations implicitly.
