---
title: "Connect an external wallet"
description: "Connect a user-controlled EVM wallet safely on Arc Testnet."
---

The Arc Testnet web app uses Reown AppKit with Wagmi for external EVM wallets only. WalletConnect and compatible injected wallets include Rabby, Trust Wallet, MetaMask, Binance Wallet, and others exposed through AppKit.

1. Select **Connect wallet**.
2. Choose a detected injected wallet or a WalletConnect-compatible wallet.
3. Approve the connection in that wallet.
4. Confirm **Arc Testnet**, chain ID `5042002`, and the intended address.
5. If Arc Testnet is unknown to the wallet, approve the add-network request containing the official RPC and ArcScan metadata.

The connected external address is the active signer. Account or chain changes invalidate the previous transaction context. The app has no email or social sign-in, hosted wallet creation, custodial wallet, developer signer, or backend signing fallback.

<Warning>
  Never enter a seed phrase or private key into the app, its documentation, a support message, or a transaction form. A legitimate connection or signature request is approved inside your external wallet.
</Warning>

## Reown project setup

Create a project in the Reown Dashboard and place its browser-public project ID in `NEXT_PUBLIC_REOWN_PROJECT_ID`. Configure AppKit metadata with `NEXT_PUBLIC_APP_NAME` and `NEXT_PUBLIC_APP_URL`. `NEXT_PUBLIC_APP_NAME` safely defaults to `Cooket`; `NEXT_PUBLIC_APP_URL` safely defaults to `http://localhost:3200` for local development and must be `https://testnet.cooket.fun` in production.

Do not use the separate Base production domain as Arc metadata. Reown project IDs are public configuration, but private keys, wallet secrets, and unrelated credentials must remain outside the frontend and repository.

See [Wallet safety](/docs/security/wallet-safety) for transaction-checking guidance.
