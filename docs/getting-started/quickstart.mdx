## 1. Run the Arc migration build

Use this repository's local Arc Testnet environment. The Base production site is separate and is not an Arc endpoint.

## 2. Connect an external wallet

Select **Connect wallet** and choose a compatible injected or WalletConnect wallet. Confirm Arc Testnet, chain ID `5042002`, and the intended active address. Email, social, and hosted wallet creation are disabled.

## 3. Do not submit financial transactions

Creation, buying, selling, approvals, graduation, and inherited deployment paths are intentionally disabled during Phase 0. Do not interpret inherited ETH or Base protocol economics as Arc native USDC economics.

## 4. Choose an action

- Browse newest, trending, or searchable launches.
- Open a token page to review its lifecycle, indexed trades, chart, and activity.
- Inspect the migration status and disabled-action messaging.
- Verify that unsupported contract, oracle, DEX, and indexer paths fail closed.

## 5. Confirm and verify

Confirm that the UI identifies Arc Testnet and does not offer inherited financial execution. No Arc Cooket protocol contracts are configured or deployed in Phase 0.

<Warning>
  Arc native USDC values use 18-decimal native units. ERC-20 USDC uses 6 decimals and is a separate representation; never mix the two.
</Warning>
